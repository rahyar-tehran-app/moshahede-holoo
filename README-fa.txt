مشاهده هلو - نسخه اندروید

قابلیت‌ها:
- نام برنامه: مشاهده هلو
- آیکون: بازسازی نشان قرمز از عکس ارسالی کاربر
- باز کردن مستقیم فایل JSON از فایل‌منیجر اندروید با گزینه «مشاهده هلو»
- نمایش اطلاعات در همان صفحه HTML موبایل و حفظ جست‌وجوی طرف‌حساب، فاکتورها و صورت‌حساب معین
- کارکرد آفلاین پس از نصب

ساخت APK:
این پوشه یک پروژه Android Studio است. برای ساخت APK از Android Studio نسخه سازگار با Android Gradle Plugin 8.6.1 و JDK 17 استفاده کنید.
یا پروژه را در GitHub قرار دهید؛ فایل .github/workflows/build-apk.yml به‌صورت خودکار APK آزمایشی را در بخش Actions به‌عنوان Artifact می‌سازد.

شناسه برنامه: ir.holoo.viewer
حداقل اندروید: Android 6.0 (API 23)

نکته: برای باز کردن مستقیم، فایل JSON را در فایل‌منیجر لمس کنید و از فهرست برنامه‌ها «مشاهده هلو» را انتخاب کنید. در صورت نمایش گزینه «همیشه»، می‌توانید آن را انتخاب کنید تا دفعات بعد ساده‌تر باز شود.
